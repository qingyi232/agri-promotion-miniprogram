# 农产品推广协同链小程序

## 项目简介
基于微信云开发的农产品故事推广小程序，致力于连接农产品产地与消费者，讲述每一份农产品背后的故事。

## 技术栈
- **前端**：微信小程序原生开发
- **后端**：微信云开发（CloudBase）
- **数据库**：云开发数据库
- **云函数**：Node.js

## 功能模块
1. **首页故事列表** - 轮播横幅 + 分类筛选 + 搜索 + 故事卡片列表
2. **故事详情页** - 图文详情 + 产地信息 + 互动数据
3. **点赞功能** - 实时点赞/取消，个人点赞列表
4. **评论功能** - 发表评论、查看评论列表
5. **推荐页** - 热门故事 + 分类推荐 + 瀑布流展示
6. **收藏功能** - 收藏/取消收藏，个人收藏列表
7. **浏览记录** - 自动记录浏览历史，支持清空
8. **个人中心** - 用户信息 + 数据统计 + 功能菜单

## 数据库集合
| 集合名 | 说明 |
|--------|------|
| stories | 故事数据 |
| comments | 评论数据 |
| likes | 点赞记录 |
| favorites | 收藏记录 |
| history | 浏览历史 |
| users | 用户信息 |

## 云函数
| 函数名 | 说明 |
|--------|------|
| stories | 故事增删改查、轮播图、热门、推荐 |
| comments | 评论列表、发表评论 |
| likes | 点赞/取消、状态检查、点赞列表 |
| favorites | 收藏/取消、状态检查、收藏列表 |
| history | 浏览记录、统计数据、清空记录 |
| init | 初始化示例数据 |

## 部署步骤

### 1. 创建云开发环境
1. 在微信开发者工具中打开本项目
2. 点击「云开发」按钮，开通云开发环境
3. 记录环境ID

### 2. 配置项目
1. 修改 `project.config.json` 中的 `appid` 为你自己的小程序 AppID
2. 如需指定云环境，在 `app.js` 的 `wx.cloud.init` 中配置 `env` 参数

### 3. 创建数据库集合
在云开发控制台 → 数据库中，创建以下集合：
- `stories`
- `comments`
- `likes`
- `favorites`
- `history`
- `users`

**重要**：每个集合的权限需设置为「所有用户可读，仅创建者可读写」或根据需要调整。

### 4. 部署云函数
右键点击 `cloudfunctions` 目录下的每个云函数文件夹，选择「上传并部署：云端安装依赖」：
- stories
- comments
- likes
- favorites
- history
- init

### 5. 初始化示例数据
首次运行小程序时，会自动调用 `init` 云函数插入示例数据（10篇农产品故事 + 6条示例评论）。

也可在云开发控制台手动触发 init 云函数：
```json
{ "action": "initData" }
```

### 6. 编译运行
在微信开发者工具中点击「编译」即可预览。
